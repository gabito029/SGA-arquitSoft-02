# Historias de usuario

| ID | Historia de usuario |
|---|---|
| HU01 | Como usuario, quiero iniciar sesión y ver solo lo que corresponde a mi rol y almacén, para trabajar de forma segura. |
| HU02 | Como almacenero, quiero registrar una solicitud de salida o de reposición con un formulario corto, para no redactar oficios. |
| HU03 | Como almacenero, quiero que las solicitudes de bajo riesgo se aprueben automáticamente, para no esperar verificaciones innecesarias. |
| HU04 | Como jefe de almacén, quiero firmar digitalmente o rechazar las solicitudes que lo requieren, para aprobar sin firmas físicas. |
| HU05 | Como almacenero del almacén de origen, quiero despachar un pedido indicando las cantidades enviadas, para que el solicitante sepa que está en camino. |
| HU06 | Como jefe de almacén, quiero confirmar lo recibido y firmar el acta de recepción, para cerrar el pedido y registrar diferencias. |
| HU07 | Como almacenero, quiero ver la línea de tiempo de cada pedido, para saber en qué estado está y quién lo atendió. |
| HU08 | Como almacenero, quiero recibir alertas de stock bajo y una sugerencia de cantidades, para reponer los materiales a tiempo. |
| HU09 | Como jefe de almacén, quiero ver las solicitudes ordenadas por prioridad, para atender primero lo urgente. |
| HU10 | Como almacenero, quiero enviar mensajes dentro de una solicitud y recibir notificaciones, para comunicarme sin documentos. |
| HU11 | Como administrador, quiero gestionar almacenes, ítems, usuarios y reglas de aprobación, para adaptar el sistema a la organización. |
| HU12 | Como administrador, quiero verificar si un documento firmado o la auditoría fueron alterados, para garantizar la trazabilidad. |
| HU13 | Como almacenero o jefe de almacén, quiero un panel de control y reportes exportables, para conocer el estado del almacén. |
