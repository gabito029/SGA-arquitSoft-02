# Historias de usuario

| ID | Historia de usuario |
|---|---|
| HU01 | Como usuario, quiero iniciar sesión y ver solo lo que corresponde a mi rol y a mi órgano, para trabajar de forma segura. |
| HU02 | Como oficial de logística de la unidad, quiero registrar un requerimiento de materiales con un formulario corto, para no redactar oficios. |
| HU03 | Como oficial de logística de la unidad, quiero registrar las salidas de materiales del almacén de mi unidad, para mantener su stock actualizado. |
| HU04 | Como comandante de la unidad, quiero dar el visto bueno o rechazar los requerimientos de mi unidad con firma digital, para autorizarlos sin documentos físicos. |
| HU05 | Como jefe de logística de la Gran Unidad, quiero dar mi conformidad o rechazar los requerimientos de las unidades de mi jurisdicción, para controlarlos según el conducto regular. |
| HU06 | Como jefe de logística del COLOGE, quiero autorizar los requerimientos de material de guerra o de montos altos, para controlar los materiales más sensibles. |
| HU07 | Como jefe de almacén, quiero aprobar o rechazar la atención de los requerimientos según el stock disponible, para atender solo lo que se puede despachar. |
| HU08 | Como oficial de logística de la unidad, quiero que los requerimientos de bajo riesgo se aprueben automáticamente en el almacén, para no esperar una firma innecesaria. |
| HU09 | Como almacenero, quiero despachar los materiales de un requerimiento aprobado indicando las cantidades enviadas, para que la unidad sepa que están en camino. |
| HU10 | Como oficial de logística de la unidad, quiero confirmar lo recibido y firmar el acta de recepción, para cerrar el requerimiento y registrar las diferencias. |
| HU11 | Como oficial de logística de la unidad, quiero ver la línea de tiempo de cada requerimiento con las firmas de cada nivel, para saber en qué paso del conducto regular se encuentra. |
| HU12 | Como oficial de logística de la unidad, quiero recibir alertas de stock bajo de mi almacén y una sugerencia de requerimiento, para abastecer a mi unidad a tiempo. |
| HU13 | Como jefe de almacén, quiero ver los requerimientos ordenados por prioridad, para atender primero lo urgente. |
| HU14 | Como usuario, quiero enviar mensajes dentro de un requerimiento y recibir notificaciones, para comunicarme sin documentos. |
| HU15 | Como administrador, quiero gestionar órganos, unidades, almacenes, ítems, usuarios y reglas de aprobación, para adaptar el sistema a la estructura del Ejército. |
| HU16 | Como auditor, quiero consultar la trazabilidad de los requerimientos y verificar si un documento firmado o la auditoría fueron alterados, para controlar la gestión logística. |
| HU17 | Como jefe de logística o jefe de almacén, quiero un panel de control interactivo y reportes exportables, para conocer el estado del abastecimiento. |
